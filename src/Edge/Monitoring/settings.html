Đang tải cấu hình…
Chưa đặt mật khẩu settings nên chưa lưu hay test được. Trên máy Edge, chạy với quyền Administrator: IndustrialIot.Edge.exe set-settings-password --service (chạy thử bằng dotnet run thì bỏ --service), rồi tải lại trang.

Lưu sẽ khởi động lại Edge: mọi PLC ngừng đọc vài giây rồi đọc lại. Nếu cấu hình mới không chạy được, Edge tự quay về cấu hình trước.
